# 拼豆先锋 BEADWATCH · 立体拼豆设计（Windows）

从 3~6 张照片生成立体拼豆模型，修形、拆件、检查后导出整套图纸。

- 在线站点：<https://shiinakuro.github.io/beadwatch/>
- 源码与发行版：<https://github.com/shiinakuro/beadwatch>

## 安装与启动

**安装版（推荐）**：从 [GitHub Releases](https://github.com/shiinakuro/beadwatch/releases/latest) 下载 `beadwatch-1.1.0-setup.exe`（页面内显示为 `拼豆先锋_v1.1.0_安装程序.exe`），双击后选好位置安装。只装到当前用户，无需管理员权限；自动创建开始菜单 / 桌面快捷方式，卸载入口进入 Windows「设置 → 应用」。
**本地 AI 依赖**：安装程序只带主程序和混元代码，不含 Python / PyTorch / 模型。打开「设置 → 本地 AI 模型」可一键安装（完整约 10 GB；只装 ISNet 抠图约 300 MB）。下载会自动测速选择最快镜像，大文件多线程分段，支持断点续传；装在程序目录下，卸载时按需保留。
**便携版**：双击 `启动拼豆先锋.cmd`（或 `app\拼豆先锋.exe`）；示例工程在 `示例\`，可直接拖进窗口打开。

自包含发布（WinUI 3 / Windows App SDK 1.8 / .NET 8），无需另装运行库。首次启动会分步带你选择本地 AI 依赖、填写生图 API（都可跳过），随后在主界面上用高亮提示认识真实按钮；方向键翻页、Esc 跳过，之后可在「帮助」中重看。

## 界面

深蓝底 + 橙蓝强调色，斜切标题与六边形元素。导航按「导入 → 编辑 → 拆分 → 检查 → 导出」排列；读条时轮播操作提示。

- 左侧：五步工作流导航 + 设置
- 中央：Direct3D 11 三维视口；浮动工具栏（动作 / 笔刷 / 镜像 / 当前色）、视角与显示开关、底部状态栏
- 右侧：当前步骤的操作卡片；顶部提示条显示结果与错误
- 空白时显示欢迎页：从图片开始 / 打开 / 空白画布 / 最近打开

## 工作流

| 步骤 | 做什么 |
|---|---|
| ① 图片导入 | 拖入图片并标注视图（正/背/左/右/顶/底）；角度随意的实拍照片标为「参考照片」。可选：AI 卡通化、AI 补全视图、对称推断侧面 |
| ② 模型编辑 | 贴豆 / 擦除 / 上色 / 选择 / 吸色 × 单格 / 整面 / 矩形 / 直线 / 填充 / 平面；X/Y/Z 镜像；剖切逐层；空心化；调色板与品牌色卡 |
| ③ 零件拆分 | 零件刷（平面填充）手工拆；一键初稿：水平分层（环片）/ 面板拆分（箱体）/ 竖切；合并碎件、碎件换向、自动齿口、重新编号；爆炸预览 |
| ④ 检查 | 漏色：内芯外露、外壳破洞、未分零件、问题零件、悬空豆、与参考图色差；装配：逐件直线插入验证，可逐步回放 |
| ⑤ 图纸导出 | 总图（标题 + 跨品牌材料表 + 零件颗粒图 + 爆炸图 + 成品效果）、零部件拆分图、分层颗粒图、整体拼装示意图、材料/尺寸清单（PNG/CSV）、A3 整卷 PDF、零件单图 |

视口操作：右键拖动旋转，中键拖动（或空格+左键）平移，滚轮缩放，Alt+左键吸色，F 居中。
快捷键：1~5 切换动作，V/G/B/L/R/P 切换笔刷，Shift+X/Y/Z 镜像，PageUp/PageDown 剖切层，Ctrl+Z/Y 撤销重做。

## 重建流程（三维）

```
参考照片 ──(gpt-image：卡通化正视图，透明底)──> 正视图 ──(以正视图为准)──> 背/左/右视图
标准视图 ─┘                                                                    │
                                                   混元3D-2mv（本地显卡，多随机种子取轮廓最吻合）
                                                                               │
                         体素化（三方向射线奇偶多数票）→ 自动对齐朝向（8 种取 IoU 最高）
                                                                               │
              多视图投影上色：法线加权选视图 · 去外描边 · 线稿骨架化成单颗豆线条 · 多数色取色 · 保边平滑
                                                                               │
                                     品牌色卡量化（CIEDE2000）· 限制颜色数 · 去杂色
```

没有显卡或混元不可用时自动退回「轮廓雕刻」（纯 CPU）。

## 图像 API（可选）

在「设置 → AI 图像服务」填入任意 OpenAI 兼容服务的根地址与 Key，点「获取模型」或离开输入框后自动读取 `/v1/models`，再从列表中挑选模型。地址可以填 `https://服务商`、`https://服务商/v1` 或完整的 `/v1/images/edits`，程序会统一归一化。

生图 API 不直接生成豆图，只做三件照片前处理：

- **整理实拍**：把杂乱背景和透视角度整理成干净的正交视图。
- **补全视角**：只拍了正面时，补出背面与侧面，减少缺面导致的破洞。
- **平涂取色**：去掉反光、渐变和阴影，让色卡量化更接近纯色。

常见可用模型：gpt-image 系列、Gemini Nano Banana 系列、Seedream、Qwen-Image 等，只要服务商支持 OpenAI 兼容的 `/v1/images/edits` 并且能返回图片即可，最终以 `/v1/models` 返回为准。没有现成服务商时可以用 [4Router](https://4router.net/register?aff=Rwm6)（推广链接，OpenAI 兼容聚合，按量计费；通过它注册不会增加你的费用）。Key 只保存在本机；启用 API 后照片会发送到所填服务商，不想上传照片可以不配置。

## 本地 AI 依赖（可选）

安装包不带数 GB 的运行时。打开「设置 → 本地 AI 模型」可一键补齐或只装抠图：

- **完整安装（约 10 GB）**：Python 3.11 + PyTorch CUDA + 混元3D 权重 + ISNet。照片在本机重建出厚度、凹槽和背面，形体比纯轮廓准；不上传照片、不消耗生图额度，装好后断网也能用。
- **仅装抠图（约 300 MB）**：ISNet + 基础运行库，CPU 即可。发丝、透明边缘和杂乱背景抠得更干净，可配合生图 API 或纯 CPU 轮廓雕刻。
- **RTX 50 系**：5080/5090 需要 CUDA 12.8 版 PyTorch；安装器会按显卡计算能力自动选择，RTX 20/30/40 继续使用 CUDA 12.1。
- 下载支持断点续传、镜像回退与 SHA-256 校验；取消后下次从已下载的部分继续。

## 已知限制

- 混元3D 生成需要 NVIDIA 显卡（实测 RTX 3070 8GB 可用，单次约 7~30 秒）。
- AI 卡通化/补视图需要配置图像 API（每张约 ¥0.15，一套四视图约 ¥0.6）；只填地址与 Key、没选模型时不会调用。
- 高度 100 层的模型按水平分层会得到上百个零件；想要更少零件可降低高度，或在零件页对局部改用竖切/面板拆分。

- 第一步同时支持多视图图片与 OBJ/GLB/STL/VOX：导入前检查朝向，有参考图时按轮廓吻合度自动转正；按选择的豆高体素化。
